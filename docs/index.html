Petrilac — página de prueba del chatbot

Esta página está pensada para probar el bot ya desplegado en Cloudflare Workers, antes de embeberlo en petrilac.com. Pegá acá abajo la URL de tu Worker (la que te da Cloudflare al desplegar, terminada en /chat) y guardala — la burbuja de chat va a usar esa URL desde este navegador.

Si el chat no responde, lo más común es un problema de CORS: en el Worker, la variable ALLOWED_ORIGIN tiene que incluir el dominio de esta página de GitHub Pages (o estar en * mientras estás probando).
